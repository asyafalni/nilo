# Object storage

**A bucket is a type, a key is a string, and the module speaks nothing of HTTP or TLS itself.** How to use it is the guide ([`guide/s3.md`](../guide/s3.md)); every method and option is the reference ([`reference/s3.md`](../reference/s3.md#nilo_s3)). The code is `s3/s3.zig` (`open`), `s3/store.zig` (the Store, credentials, signing key), `s3/bucket.zig` (`Bucket(name, opts)` and its calls), `s3/sign.zig` (SigV4), `s3/listing.zig` (the `list` XML), and `s3/canned.zig` / `s3/live.zig` (the two ways it is held to account).

## How the pieces fit

```
  s3.open(gpa, .{ endpoint, region, credentials })  ──►  Store
       one connection pool, one derived signing key,          │
       refreshed lazily against .expires_at                   │
                                                                ▼
  s3.Bucket("avatars", .{ .max_bytes, .sse, .style })  ──►  Avatars.open(&store)
       a type: name, addressing, ceilings settled                │
       while compiling, a constant SignedHeaders                 │
                                                                   ▼
                                              get / getRange / getIf / stream
                                              put / putStream / delete / head
                                              list (one page, no follow)
                                              presign / presignPost
                                                                   │
                                                                   ▼
                                                        nilo_fetch (std.http.Client
                                                        plus the gate, the deadline,
                                                        the bounded drain)
```

Everything above the last arrow is this module: signing, the bucket, the shapes a caller gets back. Everything below it is `nilo_fetch`'s, which is why `nilo_s3` adds zero packages to `build.zig.zon`.

## The rule in force

1. **A bucket is a type, not a string.** `s3.Bucket(name, opts)` returns a type; two buckets are two Services, and a handler names the one it wants by argument type, so it cannot reach the wrong one. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
2. **A key is deliberately not a type.** It is a plain runtime string, encoded once per RFC 3986 with `/` left alone; nilo never invents, normalises or validates one, so a key built from user input is the caller's own path-traversal problem. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
3. **What is comptime is a property of the bucket, not of the deployment**: name, addressing style, `max_bytes`, `sse`, `presign_max`. Endpoint, region and credentials stay runtime because `nilo_config` is what makes development and production one binary. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
4. **The header set SigV4 signs is a fixed, comptime list**, so `SignedHeaders` is a constant and signing never sorts per request; arbitrary `x-amz-meta-*` is refused, partly for that reason and partly because a metadata value could otherwise inject a header into the request being signed. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
5. **The HTTP underneath is `nilo_fetch`, itself `std.http.Client` with policy in front**, and this module adds no dependency to `build.zig.zon`: the two expensive parts of a client, TLS and a connection pool, are where the bugs and the memory are, and framing (the part nilo's own HTTP code could have shared) is a fifth of the job. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md), [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md)
6. **The gate, the deadline and the bounded drain live in `nilo_fetch`, not here**, because `nilo_s3` is a caller of the Fitting rather than the owner of an HTTP client; a second caller cost that layer one added type (`fetch.Exchange`, for a body too large to hold) and no other change. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md), [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md)
7. **A `503 SlowDown` or a 5xx surfaces as `error.Throttled` or `error.Unavailable` rather than being retried**, so a handler can shed load or answer from a cache instead of a fiber sleeping on a held permit. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md)
8. **The signing key is derived once a day and cached**, not recomputed per request: region and service are fixed at `open()`, the date changes daily, so signing costs one HMAC-SHA256 over the string-to-sign rather than five. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
9. **Credentials are fetched lazily, on the request that notices they are near `expires_at`**, with no background task; `.static` is the same mechanism with no expiry. A `.fetch` that fails fails only the request that called it, and the old key stays valid until it actually expires. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
10. **The payload hash is `UNSIGNED-PAYLOAD` over `https://` and a real SHA-256 over `http://`**, decided by the endpoint's scheme alone: over TLS the hash buys nothing TLS does not already give, and hashing costs real fiber CPU on a large body. A streamed `put` is always unsigned, since hashing what has not been read yet means reading it twice. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
11. **`getIf` returns a union, not an error**: `.unmodified` is a 304 and a success, never something a caller has to catch. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
12. **A presigned URL's life is `min(requested, presign_max, credential life)`**, and `Presigned`/`Posted` carry the true `expires_at` back, because a URL signed with temporary credentials dies when they do, whatever `X-Amz-Expires` says. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
13. **`list` answers one page and follows nothing itself**: bounded by `max_keys` and the fixed ceiling of 1,000, a larger request is `error.Rejected` rather than silently clamped, and the cursor comes back as text for the caller's own loop. There is no `listAll`. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md)
14. **A browser posts to the bucket through `presignPost`, a signed POST policy**, not a presigned link: `.max_bytes` on the policy defaults to the bucket's own ceiling and is clamped to it, never raised past it, since a browser upload is the one path that can put an object past that ceiling without nilo seeing a byte. [ADR 112](../adr/112-a-browser-uploads-with-a-form-rather-than-a-link.md)
15. **`s3.Options.public_endpoint` is the host a browser reaches, when it differs from the host this process dials.** `presign` signs that host and `presignPost` posts to it; every call that dials (`get`, `put`, `head`, `delete`) still dials and signs the process's own endpoint. Rewriting a URL's host after signing is refused as a shape, because the host is inside the signature. [ADR 177](../adr/177-a-presigned-url-names-the-host-the-browser-reaches.md)

## Open

- **`LIST` following its own cursor, `COPY` and multipart upload are not built.** All three are named on the record as where "bytes at a key" stops and a document format (XML, or an upload spread across requests) starts; [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md) and [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md) carry the reasons, and `docs/roadmap.md` is where a caller who wants one starts.
- **Binary size for a program that imports `nilo_s3` has not been measured.** [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md) says the two scratch programs for the stripped `ReleaseFast` A/B are written and unrun.
- **The stack cost of a suspended `get` at its high-water mark has not been taken.** [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md) gives the idle-connection floor as 0 bytes added but flags that number as untaken.
- **Arbitrary object metadata is refused on a performance argument that nobody has re-measured.** [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md) says the refusal can be revisited by whoever brings the number for a per-request `SignedHeaders` sort.
